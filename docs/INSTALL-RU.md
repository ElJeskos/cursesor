# Установка Game Cursor Fence 1.2.17 на другой Mac

## Что передать

Передайте файл `Game-Cursor-Fence-1.2.17-macOS-universal.dmg` через AirDrop, флешку или скачайте его из [последнего релиза](https://github.com/ElJeskos/cursesor/releases/latest).

Один установщик подходит для Apple Silicon (M1 и новее) и Intel. Минимальная версия — macOS 11. Xcode, Homebrew, исходники и сертификат с первого Mac на втором Mac не нужны.

## Установка

1. Закройте игры GameHub/CrossOver.
2. Откройте DMG и приложение `Install Game Cursor Fence.app` внутри него.
3. Если macOS блокирует запуск: эта личная сборка подписана локально, но **не нотарифицирована Apple**. Только если доверяете источнику файла, откройте **Системные настройки → Конфиденциальность и безопасность** и используйте **Всё равно открыть / Open Anyway** для этого установщика. На некоторых версиях macOS доступно Control-клик → **Открыть**. Системную защиту целиком отключать не нужно.
4. Нажмите **Установить**.
5. Разрешите **Game Cursor Fence** в двух разделах настроек: **Универсальный доступ / Accessibility** и **Мониторинг ввода / Input Monitoring**. Это разрешения управления мышью, они выдаются отдельно на каждом Mac. Если приложение не появилось в списке, добавьте `~/Applications/Game Cursor Fence.app` вручную.
6. Вернитесь в установщик и нажмите **Проверить снова**. Дождитесь сообщения об успешной установке.
7. Закройте установщик и извлеките DMG.

Приложение устанавливается в `~/Applications/Game Cursor Fence.app`, запускается автоматически при входе текущего пользователя и действует только для обнаруженной активной игры. Пароль администратора для копирования в домашнюю папку не нужен; macOS может потребовать подтверждение для выдачи разрешений.

## Проверка в игре

Клики у верхнего края должны срабатывать в безопасной точке чуть ниже полосы. Системная стрелка не должна появляться, движение камеры не должно измениться. Версия 1.2.17 проверена на отдельном принимающем окне CrossOver; проверка в Little Nightmares III и на другом Mac ещё требуется.

Установщик сохраняет предыдущую копию, если она была, в `~/Applications/Game Cursor Fence Backups`.

## Контрольная сумма (необязательно)

Положите рядом с DMG файл `.dmg.sha256`, откройте Терминал в этой папке и выполните:

```sh
shasum -a 256 -c Game-Cursor-Fence-1.2.17-macOS-universal.dmg.sha256
```

Ожидаемый результат — `OK`. Контрольная сумма проверяет целостность загрузки; доверие к источнику она не заменяет.
